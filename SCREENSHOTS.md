# LeetCode Accepted Screenshot Guide

Create a `screenshots/` folder at the repository root when you are ready to save screenshots. It is intentionally not populated; no screenshots are included or fabricated in this repository.

After you personally submit a problem on LeetCode and the result page shows **Accepted**:

1. Capture the page yourself, including enough of the page to identify the problem and its Accepted result.
2. Save the image in a new `screenshots/` folder at the repository root using the exact filename below.
3. Do not use a local test output as an Accepted screenshot.

|---|---|---|

| `02-result.png` | Reverse String | https://leetcode.com/problems/reverse-string/ |
